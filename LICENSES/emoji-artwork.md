# Additional emoji artwork and catalogue credits

Twemoji graphics: Twitter, Inc. and other contributors; community-maintained
Twemoji, https://github.com/jdecked/twemoji. Graphics are CC BY 4.0; see
twemoji-CC-BY-4.0.txt. Drawings are unmodified.

OpenMoji artwork and catalogue metadata: OpenMoji project and contributors,
https://openmoji.org/ and https://github.com/hfg-gmuend/openmoji.
CC BY-SA 4.0; see openmoji-CC-BY-SA-4.0.txt. Individual artwork authors are retained
in the generated catalogue and the selected artwork's attribution metadata.
Drawings are unmodified. Catalogue metadata is reformatted, filtered to supported
Unicode artwork, and matched to Twemoji files for search.

Selected SVG files add attribution/license metadata without altering the drawing.
Those files retain their respective artwork license. The app's code is separate.
Pinned source commits and the catalogue metadata's provenance appear in
src/static-emoji-catalog.json and scripts/sync-static-emojis.mjs.
