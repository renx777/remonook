# Claude Code instructions for RemoNook

Read these before changing anything, in this order:

1. `AGENTS.md` — project rules for every AI tool (product requirements, sync, environment parity, multi-agent workflow).
2. `docs/SYNC.md` — sync protocol v2 and the rules that protect user data.
3. `docs/ENVIRONMENTS.md` — local, staging and production, and how changes move between them.

`AGENTS.md` is the single source of truth shared with other tools such as Codex. If this file and `AGENTS.md` ever disagree, follow `AGENTS.md` and fix this file.
